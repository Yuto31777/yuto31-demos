# yuto31-demos

店舗・会社向けに先行試作したWebサイト／業務アプリのデモを公開する場所です。
QR付き名刺から、スマートフォンで試作品を開いてもらうために使います。

- 公開URL: `https://yuto31777.github.io/yuto31-demos/<フォルダ名>/`
- トップ（`index.html`）は嶋田の自己紹介ページ（自社サイトの最初の版）
- LINE公式アカウントのURLは `contact/config.js` の `lineUrl` に設定する
- 掲載しているのは試作品のみです。実在の顧客データ・個人情報は置きません。

| フォルダ | 内容 |
|---|---|
| `yohaku-coffee/` | 架空の喫茶店「余白珈琲」の予約・営業分析体験デモ（練習用） |
| `yakiniku-toraji/` | 焼肉とらじ（坂井市丸岡町羽崎）向けの店舗サイト試作。予約・お持ち帰り注文フォームのデモ付き |
| `contact/` | 嶋田へのご連絡・ご要望窓口（電話・SMS・メール・連絡先保存）。`?store=店名` で店名入りの窓口になる |
